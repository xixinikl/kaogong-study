# 资料分析每日训练（配合「行测小助手」小程序）

> 目的：每天有明确任务，不靠"想练什么练什么"。
> 用法：按下面的"今日任务"去小程序里练 → 练完把成绩页/错题截图发给 Claude → Claude 记到下方"训练记录"并定明天的任务。

## 小程序模块 → 对应我的毛病

| 小程序入口 | 练什么 | 针对的毛病 / 能力 |
|---|---|---|
| 资料分析专项 → 填空题 → **一表通算** | 同一组数据一次算出基期、增长量、比重、基期比重、比重差、隔年增长率、和/差增长率 | **看错问法、用错基数**：逼自己分清每个量用哪个公式、基数是谁 |
| 资料分析专项 → 填空题 → 百化分计算 | 分数 ↔ 百分数 | 百化分（在背），是所有估算的地基 |
| 资料分析专项 → 填空题 → 估算前期量 / 估算增长量 | 截位直除、假设分配、份数法 | 速度 |
| 资料分析专项 → 填空题 → 增量比大小 / 基期比大小 / 分数比大小 | 不算精确值只比大小 | 速度、做不完 |
| 资料分析专项 → 填空题 → 基期比重 / 年均增长率 | 公式熟练度 | 公式 |
| 资料分析专项 → 实战题（选题型、难度、题量） | 带选项的真题形式 | 综合，**计时** |
| 基础计算练习 → 五位数除三位数 / 三位数除两位数 / 乘法估算 | 纯计算 | 抄数、离谱数不警觉（练数感） |
| 数字推理训练 | — | 国考近年基本不考数字推理，**暂不练** |

## 每天的流程（约 60–70 分钟）

1. **公式默写 10 分钟**：打开「资料公式通关」https://claude.ai/artifact/8DK9bGE3kt8J2vuXhQBSA9 ，一页默写卷：纸上写完整卷 → 显示全部答案 → 没写对的点成"模糊"或"不会" → 交卷（会计时）。熟了以后用"只做没掌握的"。记录会自动保存，Claude 能读到。
2. **薄弱点专项 20 分钟**：练讲义里对应的例题，盖住解析重做。练哪个模块，看页面"薄弱点"里的红色模块，或者听 Claude 当天的安排。
3. **真题 30 分钟**：
   - 第 1～3 周：每天 1～2 篇（5～10 题），限时，每篇 6～7 分钟
   - 第 4 周起：每天 1 套 20 题，25 分钟
   - 题源：花生《资料分析 1200 题 / 600 题》按专题刷；国考、省考整套真题
4. **热身（可选）**：小程序基础计算 10 题，课间做。
5. **反馈**：把默写结果、错题号和错因、用时发给 Claude，第二天的安排就按这些来定。

## 7 周节奏（每周按反馈调整）

| 阶段 | 日期 | 做什么 |
|---|---|---|
| 诊断 | 10/08–10/11 | 前 4 天的默写覆盖全部 60 张卡，找出公式薄弱模块；真题每天 1 篇，摸清正确率和用时 |
| 专项 | 10/12–10/28 | 先补最弱的模块：讲义例题 + 1200 题对应专题；真题每天 1～2 篇 |
| 套题 | 10/29–11/18 | 每天 1 套 20 题限时；错题回到专项 |
| 保温 | 11/19–考前 | 不学新方法，默写 + 少量真题 + 回看错题本 |

**调整规则**：一个模块的默写掌握度或真题正确率低于 70%，就延长它的专项；稳定在 85% 以上就减量。每周日看一次"薄弱点"页，重排下周计划。
