# 花生十三体系的学习方法（网上整理）

> 来源是网上经验帖、课程目录和网友笔记，**不是花生十三本人的官方说明**，只当参考。2026-10-08 整理。

## 1. 学习顺序
速算专项 → 资料基础理论（ABRX、比重、盐水、比较、平均倍数、年均） → 资料总结课 → 资料刷题课 → 题库（资料分析 1200 题 / 600 题） → 套题。
**先学方法，再大量刷题，把方法变成熟练度。**

## 2. 几条被反复提到的做法
- **速算要单独练一段**：有高分考生推荐"速算 21 天"，重点练分段减法、415 份数、假设分配，用每套的用时衡量进步。
- **听课 / 看笔记不止一遍**：一遍记不住，方法要反复过。
- **"大默写"**：把速算技巧和公式默写出来自测，默不出来的就是没掌握。
- **用纸质题本**：方便圈画数据，考场也是纸质。
- **时间目标**：资料分析约 25 分钟做 20 题，**至少对 18 题，可以酌情放弃 2～3 题**。
- **选项差距大直接选，差距小才精算；超时就跳。**
- 花生十三的方法（速读、速算、直觉判断）基础好的人用起来更快。借鉴框架，结合自己的真题和错题调整，形成自己的做法。

## 3. 落到我身上（7 周）
- 速算：每天练，前 3 周是重点（小程序 + 讲义第一、二讲的练习）。
- 理论：讲义第二～七讲的**例题盖住解析重做**，等于把刷题课自己过一遍。
- 默写：每周日默写一遍 `速查表.md`，默不出来的标红。
- 刷题：有 1200 题 / 600 题就用它按专题刷；之后转整套真题限时。
- 目标：25 分钟 20 题、对 18 题。
