# 资料分析错题本

> 每套题复盘后追加一条记录；新学到的放进下面「知识卡」对应的三类：⚠️ 易错坑点 / ⚡ 提速技巧 / 🔍 题型识别。

## 做题前三问（从老毛病里提炼）
1. **问的是什么？** 增量 / 增速 / 比重 / 倍数 / 平均数——圈出问法关键词再算。
2. **基数是谁？** 是总额还是其中某一项？是今年还是去年？
3. **材料里有没有现成的？** 先扫一眼材料，找不到再自己算。

> ⚠️ **审题陷阱速记**：相隔 ≠ 相差（2 月到 8 月相隔 5 个月）｜超过不含等于｜幅度看绝对值｜"下降了"往回推要加回去

算完再问一句：**这个数离不离谱？**（量级、正负、和其他数据对不对得上）

## 两条总规则（10/10 归纳）
- **规则1 · 数的主人**：代数之前，每个数旁边先写上它的主人（谁的、哪年、哪一列）；总计行 / 总指数列先划掉。大部分错都属于这条。
- **规则2 · 凑整验算**：算完用凑整再估一遍；差值小的时候，数字多留几位。

## 🗂 知识卡（按用途分三类，做题前扫一眼 ⚠️，算的时候用 ⚡）

### ⚠️ 一、易错坑点（审题 / 数的主人）
> 出题人故意挖的坑，**读题时**对照。

| 坑 | 正确做法 | 出处 |
|---|---|---|
| **⭐ 时间段要对上** | 问"十二五期间"（2010 末→2015 末），材料里的"增长 4.1%"是比上年 → 不能用，要拿 2010 和 2015 两个数自己比 | 联考A 118 |
| 年份差 | "十二五期初" = 2010 年末，到 2015 年末是 **5** 年，不是 6 年 | 联考A 116 |
| **⭐⭐ 算反面要翻回来：问合格率就别停在不合格率** | 为了好算改用反面（不合格率 = 不合格量 ÷ 抽检量）完全可以，但排序方向要反过来：不合格率越小 → 合格率越高。动笔前在草稿写"问：合格率 高→低"，算完对一眼 | 2022国考执法 114（10/17） |
| **⭐⭐ 年均增长率估算：先减 1 再除 n** | r ≈ (末÷基 **− 1**) ÷ n：200→260 是 (1.3 − 1)÷5 = 6%，真值略小 → 5.4%。把 1.3 直接除 5 得 26% 是离谱数。陷阱：没往小修的 6%、n 数成 6 年的 5% | 10/13 公式卡 n3 |
| **⭐⭐ 年均估算只给上限，选项近必须代边界验** | 400→600（5 年）估 10% 偏大 → 只知道 <10%。选项按 1 个点切开就代边界：1.09⁵ ≈ 1.53 > 1.5、1.08⁵ ≈ 1.47 < 1.5 → 8%～9%（讲义外速记：(1+r)⁵ ≈ 1 + 5r + 10r²） | 10/14 小测（选了 9%～10%） |
| **⭐ 两群人对不上 → 推不出 / 算不出** | 先看选项说的是哪群人，再看材料里那个数是哪群人的（信用卡 76% 是"月收入 4000 以上"，年龄段是"贷款"的）→ 对不上直接判，不用算 | 联考A 114、115 |
| 找不到的数是藏起来的 | 20 秒在目录里找不到 → 想"差/和"关系：支出 = 收入 − 存款 | 联考A 113 |
| **⭐⭐ 相隔 ≠ 相差（很可恶）** | 2 月和 8 月**相隔 5 个月**（数中间有几个，像排队第 2 个和第 8 个中间隔 5 个人）；8 − 2 = 6 是相差。5 和 6 同时出现在选项里就是这个坑 | 民航篇 91 |
| **超过 / 高于 / 多于** | **不含等于**；"不低于、不少于"才含等于 | 民航篇 92 |
| **⭐"下降/上升了"往回推** | 先问"对谁而言"、**谁更大**：现在比过去下降 → 过去更大，要加回去（2010 = 32.7 **+** 3.5） | 非公有制篇 88（我自己总结的） |
| 变化幅度 / **相差最大** | 看**绝对值**，降 1.7% 也落在 1%～3% 里；"A 和 B 相差最大"两个方向都要算（77.5 和 87.5 差 10，比 97.3 和 91.5 的 5.8 大） | 第七讲例题4、2017联考A 107 |
| **⭐⭐ 选"不正确/错误"的题** | 动笔前在括号旁写个"错"字，选之前再看一眼（三个选项都判对了，最后却选了对的那个） | 2016江苏 120、吉林甲级 105 |
| 增量 vs 增速 | 圈出问法；"增长多于""新建、新增"= 增量 | 河南、人口普查 106、光缆 104 |
| 问法两边同类 | "增长多于…年平均值"→ 后面也是年均增量；另一种理解在材料里算不出来，就不是那种理解 | 非公有制篇 86 |
| 提高了几倍 vs 是几倍 | 提高几倍 = 差 ÷ 基期；是几倍 = 现 ÷ 基 | 吉林 102 |
| 总计行 / 总指数列 | 先划掉；"从…看""及""其中"前面的是总的；多系列图先对照图注认出总体（分之和 = 总） | 山东 107/109、吉林 105、光缆 104 |
| "其他"算不算一类 | 表头里列出来的类别都算（"其他"也是一列）；拿不准就两种都试，看哪个在选项里（124：不算"其他"是 18.3，选项里没有） | 2016江苏 123、124 |
| **⭐⭐ "上年同期 / 同比"** | 一出现就翻译成 **R（同比增速）**：少于上年同期 = 同比增速为负，去看增速那条线，**不是和上个月比柱子** | 2016江苏 126 |
| **⭐⭐ "X—Y 月的（月均）增速"起点是 X 的前一个月** | 数"跳了几次"：2—6 月是 2、3、4、5、6 月共 5 次增长，第一跳从 1 月起 → 起点 1 月（图表里有前一期就往前推，同速查表第 8 节）。用 2 月当起点正好掉进陷阱选项 | 2016江苏 129 |
| **表里没有的类别要自己减** | 问"成年参观者"，表里只有"参观人数"和"未成年人" → 成年 = 两列相减，不能直接看其中一列的走势。快判：2011→2012 总数只多 372，未成年多了 3305 → 成年一定降 | 2017国考 125 |
| **⭐⭐ 双胞胎词：圈两次再抄数** | 长得像的词是我最常看错的：东部 / 东北、成年 / 未成年、城市 / 农村、进口 / 出口 / 进出口、同比 / 环比、增量 / 增速、正确 / 不正确。看到其中一个，①在题干里把它圈出来，②到材料里找到**一模一样的字**再圈一次，两个圈对上了才抄数。只圈关键名词，每次 2 秒 | 10/11 一天内看错 3 次（银行 120、国考 125、联考 105） |
| **⭐⭐ 百分数先认身份** | 前面是"**占**" → 比重；前面是"**增长 / 下降**" → 增速 R。只有 R 才能进 (R1−R2)/(1+R2)。同一年里两类对象互相比"几倍" → 没有增速，是两个比值相除 | 2017国考 123 |
| **⭐⭐ 降幅收窄 / 扩大 → 去年的降幅** | 今年降 24.4%，降幅**收窄** 1.6 → 去年降得更多：26%。降幅**扩大** 1.3 → 去年降得少：今年 − 1.3。口诀：收窄是"今年好转了"，去年更糟 | 2017联考A 101、2017国考 126 |
| **往回推两年要除两次** | 问 2014、材料是 2016：先 ÷(1+今年增速) 到 2015，再 ÷(1+去年增速) 到 2014。只除一次的结果一定在选项里当陷阱（28582、29200 都是），正确答案比它们都大 | 2017联考A 101 |
| 生活叫法 ≠ 材料定义 | 研究生 = 硕士 + 博士 | 山东 106 |
| 个数 vs 比例 | 不能直接比；"万人"是单位不是"每万人"；比例 = 个数 ÷ 总人口 | 人口普查 109 |
| 轴上没单位 | 看图注定义（"之比"→ 百分数）；"日利用率""每天……"是每天的量，求一个月要 × 天数 | 民航篇 93 |
| 时间范围 | 选项的时间范围要和原文对上，才能直接用原文 | 吉林 105 |
| 材料里有现成的 | 表里没有的年份去文字里找；文字常直接给增量（如"净增加 23.69"） | 人口普查 107、非公有制 86 |
| **"上涨最多" ≠ "涨幅最大"** | 上涨最多 = 增量，涨幅最大 = 增速。平均价格的 R（R1−R2）算出来之后**还要乘以 B（现期价格）** | 2016江苏 118 |
| 选项借用材料别处的现成数 | 选项数字和材料某处一模一样但主语换了（−1.3% 是"7 大类合计"）→ 先怀疑 | 2016江苏 120、保险 113 |
| 混合平均数 | 缺权重就推不出；"两数相加 ÷ 2"是陷阱 | 吉林乙级 95 |
| 415 份数 | 不一定是 1 份：R = a/b → 基期 b 份、增量 a 份、现期 a + b 份 | 保险篇 111 |
| 约分过头 | 要比较的两个数很接近时别约成一样（2.48%、2.56% 都约成 2.5% → 差距没了） | 银行篇 118 |

### ⚡ 二、提速技巧（算的时候用）
> 能不算就不算，能只看方向就不求数值。

| 技巧 | 怎么用 | 出处 |
|---|---|---|
| 年均增长率：先算倍数再对照 | 末÷基 = (1+r)ⁿ，n = 末年 − 基期年（有前一年数据就前推）。涨得少（≈10%）→ 除以 n 再略小；涨得多 → 查表：1.05⁴≈1.22、1.1⁴≈1.46、1.15⁴≈1.75、1.2⁴≈2.07。拿不准就一年一年推验证 | 联考A 116、讲义第七讲 7.4 |
| 假设见代入：真值夹在 x' 和 A'R 之间 | 选项极近求增量：在两个最近选项**中间**取 x'（198、203 取 200）→ A' = B − x' → 算 A'×R。2180 × 9.3% ≈ 202.7 → 真值在 200～202.7 → 203。两数几乎一样 → x' 就是答案 | 10/13 公式卡 d4 |
| 比重差 / 求后期：先排除再粗估 | 比重差 < 增速差，先划掉 ≥ 增速差的；剩下用"现期比重 × 增速差"粗估，真值再小一点（30% × 8% = 2.4 → 2.1）。保持增长率求后期 → 比保持增长量的结果稍大一点 | 10/13 公式卡 p4、a8 |
| 综合题用前面题的结果 | 120 D 苹果单产 4261÷233≈18.3，直接和 117 算出的 17.64 比 | 联考A 120 |
| 选项很近的除法用基准法 | 分母 × 中间选项去凑分子：1537 × 17.75 ≈ 27280 > 27100 → 答案比 17.75 小 → A | 联考A 117 |
| **⭐ 文字材料先建目录** | 不通读：每句只圈主语名词（收入→存款→信用卡→贷款→…），眼睛跳句号、分号看后面两三个字，不画分隔线；目标 20～30 秒。之后按题里的名词跳到那一句 | 联考A 111–115（10/12 录屏：通读 1:45 → 建目录约 1 分钟） |
| 单位不统一 → 往大的换（乘），不往小的换（除） | 每月 41 × 12、每日 1.672 × 366，都换成全年；闰年看材料第一句 | 联考A 112 |
| 1.67 ≈ 5/3（百化分） | 1.672 × 366 ≈ 366 ÷ 3 × 5 = 610，再补 0.005 × 366 ≈ 2 → 612；不要列竖式 | 联考A 112 |
| **⭐ 比值只看 R1、R2** | 问升降、折线走向：分子分母**谁降得多/升得多**。例：人数降 22%（5.9→4.6）、企业数降 7.5% → 分子降得多 → 比值降。不用把比值算出来 | 农民工篇 98、第七讲例题2 |
| 同向 / 反向秒判 | 分子降、分母升 → 比值一定降；分子小降、分母减半 → 一定升 | 农民工篇 98 |
| 数反例 | "有几个月满足"→ 数不满足的，再用总数减 | 第七讲例题2、吉林乙级 99 |
| **排除法顺序** | 先验最好判断的（一乘就知道：1.78 × 200 = 356 > 348）；**每个选项至少扫一眼**；验出确定对的就停；陷阱选项常是"另一年的现成数" | 非公有制 90、吉林乙级 100、保险 113/115、农民工 100 |
| **⭐ 比率超过 75% → 不用除** | 受理率 > 75% ⇔ 受理 > 3 × 未受理（受理 : 未受理 > 3 : 1）。7 月 30932 vs 3×9361=28083 → 超过。同理 >80% ⇔ 是 4 倍，>2/3 ⇔ 是 2 倍 | 2022国考执法 118（10/17） |
| 先算门槛再看数据 | 月飞行超 300 小时：31 天的月门槛 9.68，30 天的 10，2 月 10.7 → 对着柱子数 | 民航篇 92 |
| **⭐ 盐水定性秒判** | 整体平均数靠近谁，谁的量就大；混合值一定夹在最小值和最大值之间（1.29%～1.44% 只有 1.38%） | 吉林乙级 92、银行篇 119 |
| **⭐⭐ 混合比例过线：人数×差距，多的 vs 欠的** | 问合起来过不过 50%：每组 人数 × 与线的差距，比"多出来的"和"欠的"谁大。甲 40 人 60%、乙 60 人 45% → 多 400、欠 300 → 超过（51%）。不用距离比/人数比，就不会比反；最后数人验证 | 10/14 小测（王者荣耀卡 c6，第一次判反） |
| 离谁近 | 先用 50%/10%/1% 做基准，算出多出多少再选 | 保险篇 112 |
| 基准法（我的） | 分母 × 百分比去凑分子：348 × 3% ≈ 10.4，剩 1.4 ≈ 0.4% → 3.4% | 惯用 |
| 比值增长率乘法版 | 总额倍数 = 分子倍数 × (基期率 ÷ 现期率)：1.107 × (1 − 3.1%) ≈ 1.073 | 银行篇 118 |
| 平均数的差 | = 增量公式 X = B·R/(1+R)，B 是现期平均，R 是平均数增速；选项差得远时用"现期 × R"估 | 第七讲例题3 |
| 隔级比重 | 直接相乘：11.84/348 × 57.5% ≈ 3.4% × 0.6 ≈ 2%；"工业占二产"= 47.3% ÷ 57.9% | 非公有制 87、90 |
| 倍数比较代替增速 | 年均增速比较、时间段相同 → 比"末期 ÷ 基期"倍数 | 非公有制 89 |
| **尾数法** | 多个数求和、选项尾数不同：只加尾数（.9+.5+.7+.7+.3+.9+.0 = 4.0 → .0），5 秒 | 2016江苏 119 |
| 大大则大 | 比增量：B 最大、R 也最大的那个增量一定最大 | 2016江苏 117 |
| 凑整补数减法（讲义外） | **只在要借位时用**：先减整百，多减的**加回来**，把"+几"写在草稿上别靠记。750−496 → −500 得 250，+4 → 254（不是再减 4）；不用借位的直接减 | 10/11 热身（三位数减法 16 对 12） |
| **分数比大小：分子倍数当门槛** | 比 a/b 和 c/d 不要除出来，横着比：分子是几倍 → 拿这个倍数去乘另一个分母，看够不够。2026/2.56% vs 1341/1.46%：分子 1.5 倍，1.46 × 1.5 = 2.19 < 2.56 → 分母大得更多 → 前者小。分子大、分母小时直接下结论。抄数时旁边写主人（农 / 城） | 银行篇 120 复做 |
| 表 + 图拼数据 | 表给上年的季度数，图给今年的月度柱子 → 季度 = 三根柱子相加，再和表里现成的上年同季度相减；选项尾数不同就只算尾数（9+4+4 → 7，10582 − …7 → 尾数 5） | 2016江苏 128 |
| **算之前先看选项：和"一半"比** | 比重 58% → 超过一半：593 的一半是 296，只有 344 比它大，不用乘。58.8% × 1480 → 比 740 多一点 → 870 | 2016江苏 133、134 |
