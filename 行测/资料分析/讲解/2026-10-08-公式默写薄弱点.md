## 一、比值家族（最大的薄弱块）
不会：基期比重、平均数增长率、平均数之差能否秒杀；模糊：比值增长率、两边除中间。
这几条其实是**同一个东西**：比重 = 部分 / 整体，平均数 = 总量 / 个数，都是"分子 / 分母"。分子、分母各有自己的增长率，记 R1（分子）、R2（分母）。

### 1. 基期比重（基期平均数同理）
**基期比重 = 现期比重 × (1+R整) / (1+R部)**
推导：去年部分 = 今年部分 / (1+R部)，它在分子，所以 (1+R部) 跑到分母；去年整体 = 今年整体 / (1+R整)，它在分母，所以 (1+R整) 翻到分子。记法：**部分的增长率在下面。**

例：某省 GDP 5000 亿，增长 5%；其中第三产业 2600 亿，增长 8%。求去年第三产业占比。
- 现期比重：2600 / 5000 = 52%
- 先定性：R部 8% > R整 5% → 比重上升 → 去年比 52% 小
- 再估算：52% × 1.05 / 1.08，1.05 / 1.08 ≈ 1 − 3/108 ≈ 1 − 2.8% → 52 − 52 × 2.8% ≈ 52 − 1.5 ≈ 50.5%
- 精确值：50.56% ✓

### 2. 比值增长率 = 平均数增长率
**R = (R1 − R2) / (1 + R2)**（R1 分子增速，R2 分母增速）
记法：分子比分母快多少（R1 − R2），再除以分母的 (1+R2)。

例：社零总额 1200 亿，增长 10%；人口 600 万，增长 2%。人均社零增长多少？
- R1 − R2 = 8%，除以 1.02 → 比 8% 小一点 → 约 7.8%
- 验证：1.10 / 1.02 = 1.0784 ✓
- 易错：直接写 8%（忘了除 1+R2）；或者 R1、R2 放反

### 3. 平均数之差为什么不能秒杀
比重差和平均数差的公式长得一样：**a / B × (R1 − R2)**（a 去年分子，B 今年分母）。
- 比重差：a / B 是个"占比"，一定小于 1，所以 |比重差| < |R1 − R2|，可以秒杀。
- 平均数差：a / B 是"人均多少元"，带单位，可以远大于 1，所以没法跟 R1 − R2 比，**只能算**。
- 例：上面社零的例子，a / B ≈ (1200 / 1.1) 亿 / 600 万 ≈ 1.82 万元，× 8% ≈ 0.15 万元，也就是人均多了约 1450 元。"1450 元 < 8%"根本没法比。

### 4. 两边除中间
**(A / B) ÷ (C / D) = A × D / (B × C)**：两头的 A、D 上分子，中间的 B、C 下分母。
例：甲地人均 = 600 / 30，乙地人均 = 400 / 40，甲是乙的几倍？→ 600 × 40 / (30 × 400) = 2。
真题常见问法："甲的人均是乙的多少倍"，不用先算两个人均。

## 二、化除为乘（不会）
**适用**：R 在 [−10%, 0] 最好用，[0, 10%] 也行；求增长量 X 或基期 A。
**做法**：r 为增长率的绝对值。
- 下降：r修 = r + r²，|X| ≈ B × r修
- 增长：r修 = r − r²，X ≈ B × r修
- 记法：**降了就加，涨了就减**。r² 很小：5% → 0.25%，8% → 0.64%，10% → 1%

为什么：X = B × r / (1 − r)，而 1 / (1 − r) ≈ 1 + r + r²，所以 X ≈ B × (r + r²)。增长时同理变成减。

例 1（下降）：B = 4800，下降 6.2%，求 X、A。
- r² ≈ 0.38% → r修 ≈ 6.6%
- X ≈ 4800 × 6.6% = 288 + 28.8 ≈ 317 → A ≈ 4800 + 317 = 5117
- 验证：4800 / 0.938 = 5117 ✓

例 2（增长）：B = 3150，增长 5%，求 X。
- r修 = 5% − 0.25% = 4.75%
- X ≈ 3150 × 5% − 3150 × 0.25% = 157.5 − 7.9 ≈ 150
- 验证：3150 × 5 / 105 = 150 ✓

## 三、间隔增长率逆运用（不会）
正着用：R间 = R1 + R2 + R1R2（两年连起来的增长率）。
逆着用：知道两年合计 R 和后一年 R2，求前一年 R1：
**R1 = (R − R2) / (1 + R2)**
来源：(1+R) = (1+R1)(1+R2) → 1+R1 = (1+R) / (1+R2)。跟比值增长率是同一个形状。
秒杀：R2 > 0 时，|R1| < |R − R2|。

例：2024 年比 2022 年增长 16.6%，2024 年同比增长 7%，求 2023 年增速。
- R − R2 = 9.6%，除以 1.07 → 9.6 − 9.6 × 7% ≈ 9.6 − 0.7 ≈ 8.9%
- 验证：1.166 / 1.07 = 1.0897 ✓

## 四、等比放缩（不会）
分子分母**同比例**加减，分数大小不变。用在：① 分母接近整百、整千；② 两个分数相减，把分母变成一样。

例 1：885 / 992
- 992 → 1000，加了 8，约是 992 的 0.8%
- 分子也加自己的 0.8%：885 × 0.8% ≈ 7 → 892 / 1000 = 89.2%

例 2：154 / 508
- 508 → 500，减了 8，约 1.6%
- 分子减 154 × 1.6% ≈ 2.5 → 151.5 / 500 ≈ 30.3%（精确 30.31%）
