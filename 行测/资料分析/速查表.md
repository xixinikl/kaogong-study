# 资料分析速查表（花生十三体系 · 按随堂笔记整理）

> 来源：`资料分析/随堂笔记/` 第一～七讲 + 7月4日总结。标"讲义外"的是笔记里没有、额外补充的。
> 原则：每条写"怎么估"，不写精算。

## ⚠️ 先记字母：老师的 ABRX

| 字母 | 含义 | 记法 |
|---|---|---|
| **A** | **基期**（去年 / 上期） | "与谁相比，谁为基期" |
| **B** | **现期**（今年 / 本期） | |
| **R** | 增长率 | R = X / A |
| **X** | 增长量 | X = B − A = AR = BR / (1+R) |

> 网上那份 skill 和别的书常把 A 当现期，**跟老师相反，以老师为准**。小程序「一表通算」里的"现期 A / 现期 B"是**两个不同的量**，不是这里的 A、B。

## 0. 识别题型 = 时间 + 主体 + 问题

- **时间**：现期、基期、间隔（隔年）、年均？
- **主体**：单一数，还是比值（比重、平均数、倍数）、乘积、加减（盐水）？
- **问题**：问 R 还是问 X？（我的老毛病：增量看成增速）
- 动笔前再问一句：**材料里有没有现成的？** 算完问一句：**离不离谱？**

## 1. 速算技巧

| 运算 | 方法 | 要点 |
|---|---|---|
| 加减 | **尾数法** | 选项最后一两位不同 → 只算尾数 |
| 加减 | **高位叠加** | 从高位加起，末尾两三位凑整；求和问"在哪个范围"最好用 |
| 减法 | 分段 | 错开一位分段减 |
| 乘法 | **小分互换** | ×25% = ÷4，×12.5% = ÷8，×16.7% ≈ ÷6，×33.3% ≈ ÷3 |
| 乘法 | **拆分**（"一个包子" = 1%） | 55% = 50%+5%，48% = 50%−2%，95% = 1−5%，27.5% = 25%+2.5% |
| 除法 | **拆分法** | 分子在分母 50% 附近先拆 50%；接近 1 先拆 100%；分子很小拆 10% / 5% / 1% |
| 除法 | **等比放缩** | 分子分母同比例加减，让分母变整百；两个分数加减时让分母变成一样 |

> 💡 **我的"基准法"就是老师的拆分法**：分母 × 50% / 10% / 1% 去凑分子。例：157 ÷ 354 → 354 的 50% 是 177，157 = 177 − 20，20 约占 354 的 6% → ≈ 44%。

## 2. 除法转换：求 A（基期）和 X（增量）的三把刀

已知现期 B 和增长率 R：A = B / (1+R)，X = BR / (1+R)。**按 R 的大小选方法**：

| 方法 | 适用 | 做法 |
|---|---|---|
| **化除为乘** | R 在 **[−10%, 0]** 最好用；[0, 10%] 也行 | r 为 R 的绝对值。**下降**：r修 = r + r²；**增长**：r修 = r − r²。然后 \|X\| ≈ B × r修 |
| **假设分配** | R 在 **[0, 25%]**；基期能估到某个整百数附近 | 核心 X = AR。先假设 A 是个整数，算 X = A × R，A + X 和 B 比，剩下的差再按 1 : R 分给 A 和 X |
| **415 份数** | R 接近某个**小分数** | R = 1/n → 基期 n 份、增量 1 份、现期 n+1 份。例：R = 25% → 4 : 1 : 5（名字由来） |

- 化除为乘例（讲义外，自编数）：B = 4800，R = −6.2% → r修 ≈ 6.2% + 0.4% = 6.6% → X ≈ 4800 × 6.6% ≈ 317，A ≈ 4800 + 317 = 5117。
- 假设分配例（讲义外，自编数）：B = 4800，R = 6.2% → 假设 A = 4500，X = 279，A + X = 4779，还差 21；21 差不多全给 A → A ≈ 4520，X ≈ 280。
- 415 例：R = −20% = −1/5 → 基期 5 份、X 为 −1 份、现期 4 份。
- **选项极近时用"假设见代入"**：各数保留三位后，选项差距在 1 左右，算不出来。这时在两个最近的选项**中间**取一个好算的 x'，令 A' = B − x'，再验算 A' × R 偏大还是偏小。
- **用假设分配前先判断**：数据去掉后两位、保留三位，选项差距远大于 1～2 才能用。题干数据也要同样截位。

## 3. ABRX 类

### 求 A（基期）
| 考法 | 方法 |
|---|---|
| 一般基期 | 假设分配 / 415 / 化除为乘 / 直除 |
| **间隔基期** | 先求间隔 R = R1 + R2 + R1R2，再按一般基期做 |
| 基期和差 | 两次求基期再加减（例：基期的 1～9 月 = 基期的 1～10 月 − 基期的 10 月） |
| 已知变化情况求基期 | **A = X / R**（棉花题：已知"增加 63.3，提高 6.0%"） |

### 求 B（后期 / 未来）
1. 假设 X 每年相同：B后 = B + nX（列不等式）
2. 假设 R 每年相同：B + BR，一年一年往后推
3. 按实际增速：实际增长率 ≈ 名义增长率 − 价格因素

### 求 X（增量）
1. 一般 X：415 / 假设分配 / 化除为乘
2. 两期增量之比 X2/X1：分别估。例：A1 = 2000、R1 = 3%，A2 = 6000、R2 = 6% → X2/X1 ≈ 3 × 2 = 6
3. 整体 X = X1 + X2 + X3 …

### 求 R（增长率）
1. 一般 R = X / A
2. **间隔 R = R1 + R2 + R1R2**（必须是三个连续时间点）
   - 逆运用：R1 = (R − R2) / (1 + R2)；R2 > 0 时 |R1| < |R − R2|，R2 < 0 时 |R1| > |R − R2|
3. **比值 R = (R1 − R2) / (1 + R2)**：A = B / C 型，R1 是分子增速，R2 是分母增速（平均数、"整体 = 部分 / 占比"）
4. **乘积 R = R1 + R2 + R1R2**：A = B × C 型
   - **有占比想乘积**（部分 = 整体 × 占比）
   - **有日均想乘积**（总量 = 日均 × 天数）
   - 有实际含义的乘式（总产量 = 亩产 × 面积，收入 = 产量 × 价格）

## 4. 比重类

| 考法 | 公式 / 方法 |
|---|---|
| 现期比重 | 部分 / 整体（"抓 1%"；选项有 10 倍关系时注意量级） |
| 饼状图 | 1/2、1/4、1/3、1/8 看角度；从 12 点开始顺时针排 |
| **基期比重** | **现期比重 × (1+R整) / (1+R部)**。用等比放缩算。基期平均数、基期倍数、基期比值都套这个 |
| 隔级比重 | 小比大用乘法，小比中用除法 |
| **比重升降（趋势）** | **R部 > R整 → 比重↑；R部 < R整 → 比重↓**（我会的"比增速判断占比升降"）。逆运用：比重↑ ⇒ R部 > R整 |
| **比重差（定量）** | **a / B × (R1 − R2)**，a = 去年的部分，B = 今年的整体。口诀："今年的整体分之去年的部分，乘上增长率之差"（a 用假设分配第一步估） |

比重差三步：① 判断上升还是下降，先排除一半选项 → ② 秒杀：**|比重差| < |R1 − R2|** → ③ 实在区分不开再算。

## 5. 盐水（混合）类

- **识别**：A = B / C，且 B、C 都能拆成两部分相加（时间：全年 = 上半年 + 下半年，1～7 月 = 1～6 月 + 7 月；构成：进出口 = 进口 + 出口，全国 = 城镇 + 农村）
- **三 R 排序**：R1 > R ⇔ R > R2 ⇔ R1 > R2（整体在两部分之间）
- **已知三个 R 求量之比**：十字交叉法（求出的是**基期**量之比）
- **已知两个 R 和量之比，求第三个 R**：
  1. 定性：**在中间、不在正中间，靠近量大的一边**（增长率靠近基期大的一边；R 差不大时可以用现期代替基期）
  2. 定量：**线段法**。按量的比例分线段，离整体 R 的距离和量成反比
- 例：两部分增速 −17.7% 和 −33.5%，人次约 3 : 1 → 分 4 份，每份 ≈ (33.5 − 17.7) / 4 ≈ 4% → 整体 ≈ −17.7% − 4% ≈ −21.7%

## 6. 比较类

### 比值比较（平均数、R = X/A、比重、基期）
1. **趋势法**：分子增速 > 分母增速 → 分数变大
2. **双线法**（图表题比各年增速）：看分子（增量）和分母（基期）线段长短变化
3. 放缩、拆分
4. **"王者荣耀"法**：用盐水思想把分子分母同时拆开，判断是否超过某个数。例：2701 / 5412 > 50%？5412 的一半是 2706 > 2701 → 不超过
5. 直除（实在不行再用）

### 增量比较
- **大大则大**：现期 B 大、R 也大 → X 大
- **一大一小看倍数**：B 和 R 的倍数谁大，谁的增量大
- R < 0：B 大、|R| 也大 → |X| 大；一大一小同样看倍数
- **"增量最大"：正 > 负；"变化量最大"：比绝对值**
- 差值的变化（笔记手写像"姚明理论（单位思想）"）：今年进口 1000 ↑10%、出口 800 ↑8% → X进 ≈ 1000/11 ≈ 91 > X出 ≈ 800 × 8/108 ≈ 59 → 进口涨得多，逆差扩大（今年 200，去年 < 200）

### 替代比较
1. 末期 / 基期 替代年均 R（年份间隔相同时）
2. 现期 / 基期（B/A）替代 R（B、A 相差悬殊时）
3. X / B 替代 X / A
4. A / 非 A 替代 A / 整体
5. 图形高度之比替代数值之比（0 刻度要在同一水平线上）

## 7. 平均数 · 倍数

- 平均数 = 总量 / 个数（注意时间：大小月、闰年 366 天、季度个数）
- 两个平均数相除：(A/B) ÷ (C/D) = AD / BC，口诀"两边除中间"
- 基期平均数：A/B × (1+R2) / (1+R1)（同基期比重）
- 平均数趋势：R1 > R2 → 平均数↑（同比重升降）
- 平均数之差：a / B × (R1 − R2)，**不能用秒杀**
- 平均数增长率：(R1 − R2) / (1 + R2)
- **"是多少倍" = A / B；"多多少倍" = A / B − 1**
- 是多少倍 = 1 + R；比值倍数 = 1 + 比值 R；间隔倍数 = 1 + 间隔 R
- 环比基期增长率 = 环比基期倍数 − 1
- 翻 n 番 = 2ⁿ 倍

## 8. 年均增长量 · 年均增长率

- **年均增长量 = (末期 − 基期) / n**
- **基期年份要不要往前推**：
  - "十四五"（2021～2025）、"2021 到 2025 年这五年"：要推 → (2025 − 2020) / 5
  - 图表里有 2020 年，问 2021～2025 年均增量：要推 → (2025 − 2020) / 5
  - 图表只有 2021～2025，推不了：不推 → (2025 − 2021) / 4
- **年均增长率**：末期 / 基期 = (1 + r)ⁿ
  - 末 / 基 ≈ 1 + nr（r 很小时用，**结果偏大**）
  - 代入选项（借助间隔增长率两年两年地算）
  - **要背的数**：1.05⁴ ≈ 1.216，1.1⁴ ≈ 1.46，1.15⁴ ≈ 1.75，1.2⁴ ≈ 2.07，1.4² = 1.96（中间的数可以平均分段估）
- 年均 R 结合间隔 R：例如两年年均增长 8% → 两年合计 ≈ 16.6%（1.08² ≈ 1.166）；今年增长 7% → 去年 R = (16.6% − 7%) / (1 + 7%) ≈ 9%

## 9. 总表（7月4日总结最后一页）

| | 单一数 | 比值型（比重、平均数、倍数） | 乘积 | 加减 |
|---|---|---|---|---|
| B 现期 | A + X = A + AR | — | A × B | 盐水 |
| A 基期 | B − X = B / (1+R) | A/B × (1+R2) / (1+R1) | a × b | 盐水 |
| X 增量 | AR = BR / (1+R) | a/B × (R1 − R2) | A×B − a×b | 盐水 |
| R 增长率 | X / A | (R1 − R2) / (1+R2) | R1 + R2 + R1R2 | 盐水 |
| 趋势 | — | R1 > R2 ↑ | — | — |

> 注：总表里比值型、乘积这两列的 A、B 是"分子、分母 / 两个乘数"，a、b 是它们的基期值，跟第一列的 A 基期、B 现期不是一回事。看公式时按题型来认字母。
