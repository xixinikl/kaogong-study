## 这本书长什么样

- 60 套，每套 10 题，各题型混着出。老师在前言里说：**整体偏难，越往后越难，前几套错几道不要纠结**。
- 每套的整体难度都在 5.5～6.5 / 10 之间，套与套差别不大。**差别在题与题之间**：一套里通常有 2～3 道简单题、5～6 道中等题、1～3 道难题。
- 所以按套从头刷到尾效率不高，应该**挑着做**。

## 选题规则

**第一步：把题型分成三类**

| 类 | 题型 | 理由 |
|---|---|---|
| **A 主攻** | 工程、和差倍比、经济利润、浓度、最值、容斥、日期周期、植树方阵 | 套路固定，平均难度低，学了就能拿分 |
| **B 选做类** | 行程、几何、概率、数列余数 | 简单的和难的差别很大，只做中等以下的 |
| **C 只做简单的** | 排列组合、统筹规划、其他 | 排列组合是全书最难的一类（62 题里 22 题四星以上） |

**第二步：按难度定四档**

| 档 | 规则 | 题数 |
|---|---|---|
| **先做** | 两星半及以下，不分题型 | 217 |
| **再做** | 三星，且属于 A、B 类 | 161 |
| **选做** | 三星的 C 类；三星半的 A、B 类 | 99 |
| **跳过** | 四星及以上；三星半的 C 类 | 123 |

## 怎么用

1. **第一轮只做"先做"的 217 题**，平均每套 3～4 道。每天 5～6 道，六周能做完。
2. **按题型做，不按套做。** 打开 `按题型清单.md`，一次做一类：先翻对应那一讲的笔记把方法过一遍，再做这一类的"先做"清单。这样方法是成块的，不会做一道忘一道。
3. 建议的题型顺序（从最容易拿分的开始）：
   工程 → 和差倍比 → 经济利润 → 最值 → 容斥 → 日期周期 → 浓度、植树方阵 → 行程 → 几何 → 概率 → 排列组合（只做先做的）。
4. 第一轮做完，正确率稳定了，再开"再做"的 161 题。
5. "跳过"的 123 题，考前不用碰。

## 考场上该不该做

国考数量 10～15 道（看卷别），绝大多数人做不完。用和练习时同一套判断：

- **看到就做**：工程、和差倍比、经济利润、容斥、最值、日期，题干不长、数字不怪的。
- **看一眼再决定**：行程、几何、概率。一眼能看出用哪个套路就做，看不出就跳。
- **默认跳过**：排列组合里情境复杂的、统筹规划、题干超过四行的、图形很怪的。
- 每道题给自己 60～90 秒。到时间没思路，蒙一个往下走。
