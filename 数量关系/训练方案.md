# 数量关系 · 训练方案（10/12 和 Claude 商量定的）

> 目的：考场上用最少的时间拿最多的分。要练的是三件事：**10 秒内判断做不做**、**会做的题型做熟**、**控制时间**。
> 每天约 40 分钟，够讲一个知识点加做两组。主攻仍是资料分析。

## 每个板块的流程

1. **讲知识点（约 10 分钟）**：Claude 按 `随堂笔记/` 对应那一讲讲核心套路和秒杀技巧，给一张小抄。不讲笔记以外的花样。
2. **先判断，再动笔**：每道题动笔前用 10 秒写三样：题型、做还是跳、估几星。做完对 `题库/题库.json` 里的 star（解析原书标的）。Claude 记录估得准不准。
3. **5 题一组，限时做**：从该板块的"先做"里按难度从低到高出，每题 90 秒。做完发答案和用时，Claude 逐题讲；做对的也看有没有更快的方法、是不是蒙的。
4. **按规则决定下一步**：

| 这一组的表现 | 下一步 |
|---|---|
| 对 4 道以上，且平均不超 90 秒 | 升一档难度 |
| 对 3 道 | 同难度再来一组 |
| 对 2 道以下 | 重讲知识点，再来一组同难度的 |
| 三星难度连续两组达标 | **板块毕业**，换下一个 |

每个板块最多 20～25 题。到这个数还没毕业就先放下，标记为"考场只做简单的"。

## 板块顺序

工程 → 和差倍比 → 经济利润 → 最值 → 容斥 → 日期周期 → 浓度、植树方阵 → 行程 → 几何 → 概率 → 排列组合（只做先做的）。

## 出题方式

题目文字、选项、答案、解析、配图都在 `题库/题库.json`（600 题，71 题带图，图在 `题库/题图/`）。Claude 直接从里面按板块和难度挑题发给我，不用我去翻题本。
